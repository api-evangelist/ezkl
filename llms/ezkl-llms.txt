# EZKL

> EZKL (by Zkonduit Inc.) is a developer-friendly engine for verifiable AI and analytics. It generates zero-knowledge proofs (ZK-SNARKs, Halo2) for machine learning model inference: given a model in ONNX format and sample input, EZKL compiles a proving circuit and produces a cryptographic proof that a computation ran correctly — without revealing the underlying data or model weights. Proofs are verifiable on-chain (EVM), in the browser, or on edge devices. EZKL ships as a CLI, Python and JavaScript bindings, and a Rust library; Lilith is its high-performance compute cluster for cloud-scale proof generation.

This file was generated by the API Evangelist enrichment pipeline from the public EZKL surface. EZKL is an open-source library/CLI rather than a hosted REST API, so there is no OpenAPI/webhook surface to index.
